# NOTEPRO - Mobile To-Do App

Простое мобильное приложение для управления задачами (To-Do List), разработанное на React Native.

## 🚀 Функционал
* Добавление новых задач
* Удаление выполненных задач
* Интуитивно понятный интерфейс

## 🛠 Стек технологий
* React Native
* Expo
* JavaScript
* AI-ассистированная разработка (Claude Code)

## 📱 Как запустить
Приложение можно запустить через Expo Go. Для этого отсканируйте QR-код в проекте на платформе Expo Snack.
